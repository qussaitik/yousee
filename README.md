# طلعني معك — Android WebView

مشروع Android بسيط يعرض موقع https://talini.lovable.app/ داخل تطبيق أندرويد باستخدام WebView.

## ما الذي يتضمنه؟
- فتح الصفحة الرئيسية داخل التطبيق.
- JavaScript وDOM Storage مفعّلان لدعم تطبيق الويب.
- زر الرجوع يتنقل داخل صفحات الموقع.
- روابط الاتصال والبريد والرسائل والتطبيقات الخارجية تُفتح عبر التطبيقات المناسبة.
- أيقونة Android مخصصة أولية باسم «طلعني معك».
- GitHub Actions لبناء APK تجريبي تلقائيًا.

## بناء APK محليًا
المتطلبات: JDK 17 وAndroid SDK وGradle 8.9.

من جذر المشروع:
```bash
gradle assembleDebug
```
الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

## بناء APK من GitHub
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. افتح تبويب **Actions**.
3. شغّل **Build Android APK** أو ادفع commit إلى فرع `main`.
4. افتح نتيجة التشغيل الناجحة ونزّل artifact باسم `talini-debug-apk`.

## النشر على Google Play
Google Play يحتاج عادةً ملف AAB موقّعًا. هذا المشروع لا يحتوي على مفتاح توقيع خاص، ولا ينبغي وضع مفاتيح التوقيع في الكود أو المستودع.
قبل النشر:
1. أنشئ مفتاح توقيع release آمنًا واحتفظ بنسخة احتياطية منه.
2. أضف بيانات التوقيع كـ GitHub Actions Secrets.
3. أضف إعداد release signing إلى `app/build.gradle.kts`.
4. ابنِ AAB وجرّبه على مسار الاختبار الداخلي في Play Console.
5. أكمل بيانات المتجر وسياسة الخصوصية وتصنيف المحتوى.

## ملاحظات مهمة
- التطبيق يعتمد على اتصال الإنترنت والموقع المنشور؛ لا يعمل دون إنترنت إلا إذا بُنيت وظائف offline بشكل منفصل.
- هذه حزمة بداية. يجب اختبار كل وظائف الموقع على جهاز Android حقيقي، خصوصًا تسجيل الدخول، رفع الملفات، الروابط الخارجية، وأي تدفقات دفع أو خرائط.
- إذا تغيّر نطاق الموقع، حدّث `HOME_URL` و`APP_HOST` في `MainActivity.java`.
- قبل النشر العام، راجع متطلبات Google Play الحالية وسياسة الخصوصية الخاصة بموقعك.
